# LGLoon

适用于 iOS Loon 3.5.1（build 983）及以上版本。

在 Loon 的插件列表中添加所需插件，粘贴对应的 URL。

- **YouTube 和 Spotify**　<https://raw.githubusercontent.com/Norvon/LGLoon/main/plugins/LGLoon.lpx>

已添加过媒体插件时，在插件列表中更新它。Loon 会自动下载两份脚本。插件列表中显示的日期就是当前版本，更新后核对它是否变成最新日期。

开启复写、脚本和 MitM，并信任自己的 MitM 证书，即可在媒体插件中分别开关 YouTube 和 Spotify。
